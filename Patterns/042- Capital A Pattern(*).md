# Capital A Pattern

## Problem Statement

Given an integer `N`, print a capital `A`-like pattern using `*` characters.

The pattern generated by this solution has:

* `N` rows.
* `N / 2 + 1` columns.
* A top row with `*` between the two end positions.
* Left and right vertical boundaries.
* A horizontal bar at row `N / 2`.
* Spaces between the vertical boundaries.

For example, when:

```text
N = 6
```

the output produced by the code is:

```text
 ***
*  *
*  *
****
*  *
*  *
```

---

# Approach

The solution uses **nested loops and conditional checks** to construct the pattern position by position.

The outer loop controls the rows:

```text
i = 0 to N - 1
```

The inner loop controls the columns:

```text
j = 0 to N / 2
```

Therefore, the pattern has:

```text
N × (N / 2 + 1)
```

positions.

For every position `(i, j)`, the code checks four important conditions:

* `i == 0` → top row
* `j == 0` → left boundary
* `i == n / 2` → middle horizontal bar
* `j == n / 2` → right boundary

If any of these conditions is true, the position normally prints `*`.

There is one special case for the **first row**:

```text
i == 0 && (j == 0 || j == n / 2)
```

This means:

> If we are on the first row and at either the first or last position of that row, print a space instead of `*`.

This produces the top row:

```text
 ***
```

rather than:

```text
****
```

All remaining positions are printed as spaces.

---

# Code

```java
package Patterns;

import java.util.*;

public class CaptialApatt {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= n / 2; j++) {
                if (i == 0 || j == 0 || i == n / 2 || j == n / 2) {
                    if (i == 0 && (j == 0 || j == n / 2)) {
                        System.out.print(" ");
                    } else {
                        System.out.print("*");
                    }
                } else {
                    System.out.print(" ");
                }
            }

            System.out.println();
        }

        sc.close();
    }
}
```

# Understanding the Code

## 1. Read the Input

```text
int n = sc.nextInt();
```

The program reads the value of `N`.

For example:

```text
N = 6
```

This value determines both the number of rows and the number of columns used by the pattern.

---

## 2. Outer Loop — Rows

```text
for (int i = 0; i < n; i++)
```

The outer loop controls the number of rows.

Since `i` starts at `0` and continues while `i < n`, it runs exactly `N` times.

For `N = 6`:

```text
i = 0
i = 1
i = 2
i = 3
i = 4
i = 5
```

Therefore:

```text
Number of rows = 6
```

---

## 3. Inner Loop — Columns

```text
for (int j = 0; j <= n / 2; j++)
```

The inner loop controls the number of positions in each row.

Since `j` starts at `0` and ends at `n / 2`, the total number of iterations is:

```text
N / 2 + 1
```

For `N = 6`:

```text
6 / 2 + 1
= 3 + 1
= 4
```

Therefore:

```text
Number of columns = 4
```

So the pattern dimensions are:

```text
6 × 4
```

---

# Understanding the Conditions

The main condition is:

```text
if (i == 0 || j == 0 || i == n / 2 || j == n / 2)
```

This checks whether the current position belongs to one of the required boundaries.

### `i == 0`

This identifies the first row.

```text
i = 0
```

The first row is handled specially to create the top of the pattern.

---

### `j == 0`

This identifies the first column.

It creates the **left vertical side** of the pattern.

---

### `i == n / 2`

This identifies the middle row.

For `N = 6`:

```text
n / 2 = 3
```

Therefore:

```text
i = 3
```

becomes the middle horizontal bar:

```text
****
```

---

### `j == n / 2`

This identifies the last column.

For `N = 6`:

```text
j = 3
```

This creates the **right vertical side**.

---

# Top-Row Corner Handling

The most important special condition is:

```text
if (i == 0 && (j == 0 || j == n / 2))
```

This condition applies **only to the first row**.

For `N = 6`:

```text
n / 2 = 3
```

The first row has:

```text
j = 0, 1, 2, 3
```

Now evaluate each position:

| `i` | `j` | Position                  | Output |
| --: | --: | ------------------------- | ------ |
|   0 |   0 | First position of top row | Space  |
|   0 |   1 | Inside top row            | `*`    |
|   0 |   2 | Inside top row            | `*`    |
|   0 |   3 | Last position of top row  | Space  |

Therefore, the first row becomes:

```text
 ***
```

The important point is that these are the **first and last positions of the top row**, not necessarily geometric corners of a full rectangular pattern.

# Why This Solution Works

The pattern is constructed by checking every position and deciding whether it should contain a `*` or a space.

The four main conditions create the structural parts:

```text
i == 0
```

creates the top row.

```text
j == 0
```

creates the left vertical boundary.

```text
j == n / 2
```

creates the right vertical boundary.

```text
i == n / 2
```

creates the middle horizontal bar.

The additional top-row condition:

```text
i == 0 && (j == 0 || j == n / 2)
```

replaces the first and last positions of the top row with spaces.

This combination produces the `A`-like pattern generated by the program.

---

# Approach Evaluation

**Approach Type:** Conditional Pattern Construction

The approach is valid and directly constructs the pattern using nested loops and boundary conditions.

Instead of storing the pattern in an array, the solution evaluates each position while traversing it and immediately prints the required character.

The conditions clearly represent the structural components of the pattern, making the approach suitable for this type of pattern problem.

---

# Time Complexity

The outer loop runs `N` times.

The inner loop runs:

```text
N / 2 + 1
```

times for every row.

Therefore, the total number of iterations is:

```text
N × (N / 2 + 1)
```

Ignoring constants:

**Time Complexity: O(N²)**

---

# Space Complexity

The solution does not use any additional array, list, or other data structure.

Only the input variable and loop variables are used.

**Space Complexity: O(1)**

---

# Key Takeaways

* The pattern has **N rows**.
* The pattern has **N / 2 + 1 columns**.
* Nested loops are used to visit every position.
* `i == 0` identifies the top row.
* `j == 0` creates the left vertical boundary.
* `j == n / 2` creates the right vertical boundary.
* `i == n / 2` creates the middle horizontal bar.
* On the top row, the first and last positions are intentionally printed as spaces.
* All other non-boundary positions are spaces.
* Time Complexity: **O(N²)**
* Space Complexity: **O(1)**
