# Subsets

## Problem Statement

Given an integer array `nums` containing unique elements, return all possible subsets of the array.

The solution must include:

* The empty subset.
* Every individual element.
* Every possible combination of elements.
* The complete array.

For example:

```text
Input:
nums = [1, 2, 3]
```

The possible subsets are:

```text
[]
[1]
[2]
[3]
[1, 2]
[1, 3]
[2, 3]
[1, 2, 3]
```

The order of the subsets does not matter.

---

# Approach

This solution uses **recursion with backtracking**.

At every index, there are exactly two choices for the current element:

1. **Take** the element.
2. **Do not take** the element.

For every element, the recursion explores both possibilities.

For example, for:

```text
nums = [1, 2, 3]
```

For `1`:

```text
Take 1
Don't take 1
```

Then for each of those choices, the same decision is made for `2`, and then for `3`.

This creates a binary decision tree containing all possible subsets.

The important backtracking step is:

```text
current.remove(current.size() - 1);
```

After exploring the branch where an element is taken, that element is removed before exploring the branch where the element is not taken.

---

# Code

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();

        backtracking(nums, 0, new ArrayList<>(), result);

        return result;
    }

    public static void backtracking(int[] nums, int index, List<Integer> current, List<List<Integer>> result) {
        if (nums.length == index) {
            result.add(new ArrayList<>(current));
            return;
        }

        current.add(nums[index]);

        backtracking(nums, index + 1, current, result);

        current.remove(current.size() - 1);

        backtracking(nums, index + 1, current, result);
    }
}
```

# Understanding the Code

## 1. Create the Result List

```text
List<List<Integer>> result = new ArrayList<>();
```

`result` stores all the subsets generated by the recursion.

For:

```text
nums = [1, 2, 3]
```

the final `result` will contain 8 subsets.

---

## 2. Start Backtracking

```text
backtracking(nums, 0, new ArrayList<>(), result);
```

The recursion starts with:

```text
index = 0
current = []
```

So initially:

```text
current = []
```

The first element is:

```text
nums[0] = 1
```

---

## 3. Base Case

```text
if (nums.length == index)
```

When:

```text
index == nums.length
```

there are no more elements to process.

At that point:

```text
result.add(new ArrayList<>(current));
```

adds the current subset to the result.

A new `ArrayList` is created because `current` continues changing during backtracking.

---

## 4. Take the Current Element

```text
current.add(nums[index]);
```

The current element is added to the subset.

For example:

```text
current = []
index = 0
nums[index] = 1
```

After:

```text
current.add(1);
```

we get:

```text
current = [1]
```

The recursion then continues with:

```text
index + 1
```

---

## 5. Explore the Take Branch

```text
backtracking(nums, index + 1, current, result);
```

This means:

> We have chosen the current element, so move to the next element.

For example:

```text
[1]
```

then:

```text
[1, 2]
```

then:

```text
[1, 2, 3]
```

Eventually, this reaches the base case and stores:

```text
[1, 2, 3]
```

---

## 6. Backtrack

After the take branch is completely explored:

```text
current.remove(current.size() - 1);
```

The most recently added element is removed.

For example:

```text
current = [1, 2, 3]
```

After backtracking:

```text
current = [1, 2]
```

This allows the recursion to explore another possibility.

This is the key backtracking operation.

---

## 7. Explore the Don't-Take Branch

After removing the element:

```text
backtracking(nums, index + 1, current, result);
```

The recursion moves to the next index without adding the current element.

So if the current subset is:

```text
[1, 2]
```

the recursion can now explore:

```text
[1, 2]
```

without adding `3`.

Eventually, this generates:

```text
[1, 2]
```

# Recursion and Backtracking Flow

Consider:

```text
nums = [1, 2, 3]
```

The recursion starts with:

```text
[]
```

For `1`, there are two choices:

```text
                    []
                  /    \
               take    don't take
                1          |
               [1]         []
```

Now each branch makes the same decision for `2`.

The complete decision tree is:

```text
                         []
                       /    \
                     [1]     []
                    /  \     /  \
                 [1,2] [1] [2]  []
                  / \   / \ / \  / \
        [1,2,3] [1,2] [1,3] [1] [2,3] [2] [3] []
```

Each level represents one element:

```text
Level 0 → 1
Level 1 → 2
Level 2 → 3
```

At every level:

```text
Take
   or
Don't Take
```

Therefore, for `N` elements, there are:

```text
2^N
```

possible subsets.

For `N = 3`:

```text
2^3 = 8
```

# Understanding Backtracking

Backtracking happens at this line:

```text
current.remove(current.size() - 1);
```

The basic process is:

```text
Choose
  ↓
Explore
  ↓
Undo the choice
  ↓
Explore the other choice
```

For example:

```text
current = [1, 2, 3]

        ↓ remove 3

current = [1, 2]
```

The recursion can now try the path where `3` is not selected.

Then:

```text
current = [1, 2]

        ↓ remove 2

current = [1]
```

Now it can explore the possibilities where `2` is not selected.

This repeated **choose → explore → undo** process is backtracking.

---

# Why `new ArrayList<>(current)` Is Important

The base case contains:

```text
result.add(new ArrayList<>(current));
```

A copy of `current` is stored instead of directly storing `current`.

This is important because `current` is continuously modified during backtracking.

For example:

```text
current = [1, 2, 3]
```

If we store the same list reference and later remove elements, the stored result would also change.

Creating:

```text
new ArrayList<>(current)
```

creates an independent copy of the current subset.

# Why This Solution Works

Every element has exactly two possibilities:

```text
Take the element
Don't take the element
```

For `N` elements, these two choices create:

```text
2 × 2 × 2 × ... × 2
```

which gives:

```text
2^N
```

possible combinations.

The recursion explores both choices for every element, so no subset is missed.

The backtracking step restores `current` after exploring the take branch, allowing the recursion to correctly explore the don't-take branch.

Therefore, every possible subset is generated exactly once.

# Approach Evaluation

**Approach Type:** Recursion + Backtracking

Your approach is a standard and correct backtracking solution for generating all subsets.

The important ideas in your implementation are:

* Two choices for every element.
* Recursive exploration of both choices.
* Removing the last selected element before exploring the second branch.
* Copying `current` when storing a completed subset.

This approach is especially useful for understanding **recursion, decision trees, and backtracking**.

# Time Complexity

There are:

```text
2^N
```

possible subsets.

Each subset can contain up to `N` elements, and a copy of `current` is created when a subset is added.

Therefore:

**Time Complexity: O(N × 2^N)**

# Space Complexity

The recursion depth can reach:

```text
N
```

so the recursion stack requires:

```text
O(N)
```

The `current` list can also contain up to `N` elements:

```text
O(N)
```

The output itself contains `2^N` subsets, requiring:

```text
O(N × 2^N)
```

space.

Therefore, including the required output:

**Space Complexity: O(N × 2^N)**

Auxiliary recursion space excluding the output is:

**O(N)**

# Key Takeaways

* Every element has two choices: **take** or **don't take**.
* These choices form a binary recursion tree.
* `current` stores the subset being constructed.
* `current.add()` makes the current choice.
* Recursive call explores that choice.
* `current.remove()` undoes the choice and performs the backtracking.
* The second recursive call explores the branch where the element is not selected.
* `new ArrayList<>(current)` stores an independent copy of the subset.
* `N` elements produce exactly `2^N` subsets.
* Time Complexity: **O(N × 2^N)**
* Output Space: **O(N × 2^N)**
* Auxiliary Recursion Space: **O(N)**
